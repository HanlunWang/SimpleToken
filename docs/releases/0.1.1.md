This release changes how SimpleToken is built and shipped. The app itself works as in 0.1.0.

## Changes

- **Notarized by Apple.** The app is signed with a Developer ID and notarized, so macOS opens it without the "cannot check for malicious software" warning and without any extra steps.
- **No build-machine details in the app.** Release builds no longer carry file paths from the machine that built them.
- **Built in the open.** Releases are now built, signed and notarized by [GitHub Actions](https://github.com/HanlunWang/SimpleToken/actions/workflows/release.yml) from the tagged source, and every change on `main` is built and tested there.

## Install

Requires macOS 26 or later on Apple silicon.

Download `SimpleToken-0.1.1.zip` below, unzip it and move `SimpleToken.app` to `/Applications`. If you installed 0.1.0, quit it first and replace it; your settings and history stay as they are.

SimpleToken lives in the menu bar: click its icon for the panel, or ⌥-click for the main window. See [Getting your usage in](https://github.com/HanlunWang/SimpleToken#getting-your-usage-in) for what to set up.

The SHA-256 of the zip is in `SimpleToken-0.1.1.zip.sha256`.
