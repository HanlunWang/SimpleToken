Forecasts that work from the start of a limit window, and the right Claude plan.

## New

- **Forecasts from your usual hours.** Each limit dial now says where the window is heading by its reset (for example "Weekly → 69%"). For Claude, SimpleToken works out what one Claude Code token costs of the limit in the current window and expects the rest of the window to go like the same half-hours of your past two weeks, so the forecast is useful from the first hour, quiet nights included. Codex and Cursor keep the straight-line projection. The drop-down panel, the menu bar and the alerts use the same forecast.
- **Which window is which.** A weekly window that has just opened (after a reset or a new plan) says "New window", which is why its even-pace marker sits at zero. Hover a dial for the window's start and end: limits roll from their own start, not the calendar week.

## Fixed

- **The Claude plan follows a plan change.** The plan now comes from claude.ai itself, refreshed hourly; Claude Code's keychain item, which keeps the old plan until you sign in again, is only the fallback.

## Install

Requires macOS 26 or later on Apple silicon.

Download `SimpleToken-0.1.5.zip` below, unzip it and move `SimpleToken.app` to `/Applications`, replacing the older version (quit it first). Your settings and history stay as they are. The app is signed with a Developer ID and notarized by Apple.

The SHA-256 of the zip is in `SimpleToken-0.1.5.zip.sha256`.
