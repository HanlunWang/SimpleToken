More data in the menu bar, in the same space.

## New

- **Two new menu bar styles.** *Compact* stacks two values per column, fitting about twice as many into the same width. *Nested rings* puts up to three limits into one set of rings, in the spirit of Apple's Activity rings, with the first two percentages beside it.
- **Pace and projection on rings and bars.** A marker shows where even use would be by now: if the filled part has passed it, you are using the window faster than it lasts. A fainter extension shows where the window is heading by its reset at the current pace. Turn it off in Settings → Menu Bar.
- **Mini charts in the menu bar.** *Last 7 days* draws a bar per day with today in full strength. *Today by hour* draws a bar per hour from Claude Code's logs, with the hours still to come as dots.
- **A style gallery in Settings.** Every style is drawn with the items you picked, so you can compare them before choosing.

## Install

Requires macOS 26 or later on Apple silicon.

Download `SimpleToken-0.1.2.zip` below, unzip it and move `SimpleToken.app` to `/Applications`, replacing the older version (quit it first). Your settings and history stay as they are. The app is signed with a Developer ID and notarized by Apple.

The SHA-256 of the zip is in `SimpleToken-0.1.2.zip.sha256`.
