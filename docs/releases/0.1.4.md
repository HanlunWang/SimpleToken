Fixes for the Limits widget.

## Fixed

- **Your Claude plan shows again.** When the keychain held more than one Claude Code sign-in, SimpleToken could read an old one and show no plan. It now reads the current user's, and picks up a plan change within the hour instead of at the next launch.
- **Readable provider badges.** The Cursor / X Pass badge was a white square; logos on light badges are now drawn in dark ink.

## Changed

- **Clearer resets in the large Limits widget.** The bottom of the widget now has one line per provider: its plan, then which window resets next and when (for example "Session resets 15:50"). The countdowns stay under each dial.

## Install

Requires macOS 26 or later on Apple silicon.

Download `SimpleToken-0.1.4.zip` below, unzip it and move `SimpleToken.app` to `/Applications`, replacing the older version (quit it first). Your settings and history stay as they are. The app is signed with a Developer ID and notarized by Apple.

The SHA-256 of the zip is in `SimpleToken-0.1.4.zip.sha256`.
